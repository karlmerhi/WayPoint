# WayPoint Pet Grooming App

Mobile SaaS application for pet grooming businesses. Manages customer profiles, pet information, appointments, routes, and payments with offline functionality.

## Setup

1. Clone the repository
2. Run `npm install`
3. Create a `.env` file based on `.env.example`
4. Run `npx expo start`

## Tech Stack

- React Native with Expo
- TypeScript
- Firebase (Auth, Firestore, Storage)
- Google Maps API
- Stripe for payments
